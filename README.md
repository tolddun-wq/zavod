# «Профиль-Ока» — демо-сайт завода алюминиевого профиля

Сайт-образец для портфолио. Завод, цены, документы и люди придуманы.

## Что внутри
- `index.html` — главная: слово «ПРОФИЛЬ» с фото внутри, калькулятор резки, условия, приёмка, каталог, услуги, этапы поставки, производство, отдел продаж.
- `katalog.html` — каталог: разделы, фильтры, поиск («труба 40х3», «д16т», «ф20»), сортировка, сравнение.
- `izdelie.html?id=…` — изделие: 3D-отрезок на canvas, чертёж сечения, характеристики, расчёт хлыстов и резки.
- `sravnenie.html` — сравнение до 4 позиций.
- `zayavka.html` — заявка на КП → попадает в кабинет менеджера.
- `kabinet.html` — кабинет менеджера (демо-CRM): этапы Новая → В работе → КП отправлено → Согласовано → Оплачено → Отгружено, отказ с причиной, список и доска.
- `status.html` — статус заявки для покупателя (по номеру и почте, плюс «Ваши заявки» с этого устройства).
- `profil-po-chertezhu.html`, `rezka.html`, `proizvodstvo.html`, `dostavka.html`, `kontakty.html`, `404.html`.

## Как устроено
Статический сайт без сервера. Заявки, этапы и история хранятся в `localStorage` браузера.
Шапка и подвал общие: правятся в `index.html` и копируются в остальные страницы.
У css/js в страницах стоит `?v=N` — при правках поднимать номер.
